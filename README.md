
# Projeto UX/UI — DIO

Projeto desenvolvido durante a formação de UX/UI Design da DIO. *em desenvolvimento do curso*

## 📌 Sobre o projeto

Este projeto apresenta o processo de criação de uma interface,
desde o wireframe até a criação do Design System.

## Gabi Store: 

-W:
O projeto começou com um wireframe de media fidelidade, uma loja de moda online. A estrutura já trazia as peças essenciais de um e-commerce: 
um menu de categorias (Acessórios, Bolsas, Jeans, Saias, Vestidos), uma vitrine de produtos em destaque com navegação por setas, 
e um filtro de tamanhos (PP, P, M, G) — tudo ainda em tons neutros de cinza, sem identidade visual definida.

-DS:
A partir dessa base, o passo seguinte foi transformar o esqueleto do wireframe em um design system consistente. Primeiro veio a definição da paleta de cores:
um conjunto terroso e acolhedor:

- verde escuro (#376B57) como cor primária para ações e destaque; 
- dourado suave (#D6BF7E) para detalhes; 
- creme claro (#FFEDCB) como fundo;
- marrom escuro (#473631) para texto;
- azul acinzentado (#84A2BA) como cor de apoio. Cada tom recebeu um papel específico, pensado tanto para transmitir a personalidade da marca quanto para
manter contraste e legibilidade.

Essas cores foram inspiradas no girassol e em um ceu azul acinzentado.

Em seguida, a tipografia ganhou uma escala hierárquica — títulos, subtítulos, texto corrido e legendas — para garantir consistência visual em qualquer tela da loja.
